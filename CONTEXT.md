# CONTEXT.md

Shared vocabulary for mollys.dev.

## Glossary

- **Site**: Molly's personal homepage at mollys.dev — one retro-styled page plus a blog.
- **Section**: A titled block on the homepage: welcome, interests, media player, steam, contact.
- **Interest**: One of the four homepage topics: imageboards, cheat dev / jailbreaking / rooting, rhythm games, DIY HRT.
- **Visualizer**: The decorative spinning vinyl in the media player section. It never plays audio.
- **Contact handle**: A reachable identifier — Discord username, Telegram handle, or Session ID.
- **Blog post**: A dated, markdown-written entry shown on the blog pages.
- **Placeholder**: A stub value in the site data pending the real handle, link, or name.
